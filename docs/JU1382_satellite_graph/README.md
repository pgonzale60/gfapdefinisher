# JU1382 repeat and end network

Open [the interactive explorer](ju1382-satellite-explorer.html) in a browser. It works offline. Select a chromosome end to see the cap verdict, the source read when applicable, and local period and span estimates. Select a connection to inspect the shared block or the competing source-read alignments. [GraphML](ju1382-satellite-network.graphml) and [JSON](ju1382-satellite-data.json) expose the same evidence for other tools.

The survey takes up to 36 kb of each draft end, oriented inward from the tip, and includes two graph alternatives. Tandem period and span are estimates from local autocorrelation. Canonical 15-mer containment groups sequence-related tandem arrays. Long alignments between draft ends form separate edges because a homologous block can contain several repeat structures. The 6 bp groups include telomeric-like tracts and remain visible as local features. Representative read comparisons record conflicts seen during whole-assembly alignment. Each edge carries a verified between-arm bridge count of zero in this audit.

The [assembly report](../JU1382_GRAPH_REFINEMENT.md) gives the evidence for each accepted sequence and cap.
